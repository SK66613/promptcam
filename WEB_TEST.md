# PromptCam Web — быстрый тест на iPhone

После деплоя Cloudflare открой адрес `https://<worker>.workers.dev` в Safari на iPhone.

1. Вставь текст и настрой скорость/размер.
2. Нажми **Открыть камеру**.
3. Разреши Safari доступ к камере и микрофону.
4. Кнопка `▶` запускает/ставит суфлёр на паузу.
5. Красная кнопка делает отсчёт 3-2-1 и начинает запись.
6. Нажми красную кнопку ещё раз, чтобы остановить запись.
7. После записи выбери **Поделиться / сохранить** или **Скачать видео**.

Текст суфлёра отображается только на экране и не встраивается в записанное видео.

## Cloudflare

Проект деплоится как статические Workers Assets из папки `web/`. Существующий Deploy command можно оставить:

```bash
npx wrangler deploy
```

Build command не нужен. Конфигурация находится в `wrangler.jsonc`.
